FIRST SETUP

首次使用

  1. 打开 /setup，创建管理员账号（用户名 3–64 个字符，密码至少 8 位）。
  2. 登录后进入 /license。另开本机授权店 http://127.0.0.1:18082/，用邮箱领取激活码，再回到授权页激活。
  3. 在编辑器里配置 Home Assistant 地址和长期访问令牌，然后创建空白仪表盘。
  4. 使用 3D 交互：先在 /3d-studio 保存户型，再在编辑器添加「3D 交互」控件并载入户型快照，绑定灯或开关实体后即可在舞台里控制。
  5. 墙面中控：在编辑器生成 6 位配对码，设备打开 /pair 完成配对。

主应用默认 18081，本机授权店默认 18082。仓库根目录执行 python3 start.py 可同时启动两者。

FLOORPLAN STUDIO

户型图绘制

  1. 导入底图：在工作室左侧导入 PNG / JPG / WebP 户型图。
  2. 标定比例：用参考线工具画一段已知长度，填写真实米数。
  3. 描绘户型：连续画墙，再吸附窗户、门与栏杆。
  4. 摆放物件：从模型库拖入家具、电器与结构件。
  5. 放置灯光：添加筒射灯、吸顶灯或灯带，并按灯组管理。
  6. 保存图片：打开导图工作区，按楼层或全楼导出，图片会写回仪表盘可用的导图资源。

返回编辑器后，可用「户型自动图」或「3D 交互」控件引用导出结果。3D 交互舞台支持灯光、窗帘、空调、电视、NAS、人体存在与扫地机等绑定。
